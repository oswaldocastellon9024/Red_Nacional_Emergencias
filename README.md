## Problema y objetivo

### Problema
Existe una falta de unificación en la información entre distintos organismos de respuesta (Protección Civil, rescate y bomberos) ante desastres naturales, lo que genera duplicidad de esfuerzos y retrasos críticos en la asignación de ayuda.

### Objetivo
Desarrollar una plataforma web centralizada que reduzca en un 30% el tiempo de respuesta en la coordinación y asignación de unidades de rescate.

### Siguiente paso
Diseñar el modelo de datos para la recepción y clasificación en tiempo real de los reportes de emergencia.
